# Anthony's Ubee512 Launcher for macOS

Current Mac build: **Anthony's Ubee512 Launcher v1_5k**

## Download

Use this file:

```text
AnthonysUBee512Launcher-Mac-ARM-v1_5k.zip

````

Older Mac builds have been moved into the archive/ folder so the current download is easier to identify.

System notes

This build is for Apple Silicon Macs.

It has been tested as a launcher for an existing uBee512 setup. It does not include uBee512 itself, ROMs, disk images, or tape files.

You will need a working uBee512 installation and your uBee512 data folder set up separately.

A typical uBee512 data folder contains folders such as:

~/.ubee512/roms
~/.ubee512/disks
~/.ubee512/tapes
First launch on macOS

The macOS build is not currently Apple-notarised, so macOS may block it the first time it is opened.

If macOS blocks the app:

Open System Settings
Go to Privacy & Security
Look for the blocked app message
Choose Open Anyway

You may also need to right-click the app and choose Open the first time.

How to use
Download and unzip the current Mac build.
Move the app wherever you want to keep it.
Open the launcher.
Use Auto setup where possible.
Check that the launcher can find your uBee512 executable and your uBee512 data folder.
Scan for ROMs, disks, and tapes.
Launch uBee512.
Important limitations

This Mac build is still newer and less tested than the Linux and Windows builds.

The launcher should be treated as a helper for a working uBee512 installation, not as a full uBee512 installer.

If the emulator itself cannot find required ROMs or boot disks, check your uBee512 installation and ~/.ubee512 setup first.

Archived builds

Older Mac builds are kept in the archive/ folder for reference only.

Most users should download the current v1_5k build from this folder, not the archived versions.
